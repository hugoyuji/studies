## 🎯 Aprendizado

**Fundamentos de Java Core (Java SE):** Construção de um CRUD completo sem o uso de frameworks, manipulando coleções com `ArrayList` e iteradores (`Iterator`), além da captura de entrada de dados via `Scanner` no console.

## 💡 Retrospectiva

> Foi um excelente exercício para fixar conceitos fundamentais da POO (Programação Orientada a Objetos) e estruturas de dados em Java, trabalhando a separação de responsabilidades entre `model`, `service` e fluxo de execução no console.
